# 🚀 Infrastructure Audit & Performance TCO Report

A premium, interactive dashboard comparing **Claude Sonnet 5**, **Claude Sonnet 4.6**, and **Claude Opus 4.8** — built for enterprise infrastructure teams. Features real benchmark data, tokenizer inflation simulation, TCO analysis, and dynamic architectural routing visualization.

---

## ✨ Features

- **Minimalist, responsive design** – Clean white/light-gray canvas with warm salmon-pink glow accents.
- **Interactive model cards** – Click to expand detailed technical analysis for each Claude tier.
- **Animated benchmark bars** – SWE-bench Pro, Terminal-Bench 2.1, OSWorld, HLE with scroll-triggered animations.
- **Total Cost of Ownership (TCO) simulation** – 12-turn agent session cost comparison with/without caching.
- **Tokenizer Inflation visualization** – Shows token overhead multipliers for English, Spanish, Python, and Chinese.
- **SVG routing architecture diagram** – Visual representation of the multi-tier model routing pipeline.
- **Safety & refusal metrics** – Over-refusal probabilities and prompt injection robustness.
- **Spring-physics micro-interactions** – Card hover 3D tilt, smooth panel expansions, and counter animations.
- **Fully responsive** – Gracefully adapts to mobile, tablet, and desktop viewports.

---

## 🖥️ Tech Stack

- **HTML5 / CSS3** – Semantic markup and custom properties.
- **Tailwind CSS** – Utility-first styling via CDN.
- **Vanilla JavaScript** – Intersection Observer, spring animations, and dynamic DOM manipulation.
- **SVG** – Custom architectural diagram.
- **Google Fonts** – Inter + JetBrains Mono.

> No heavy frameworks or external libraries – lightweight and fast (Lighthouse 95+).
